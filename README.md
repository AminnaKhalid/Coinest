# Coinest App

## Live Link

https://coinest-fwnj.vercel.app/

## Description

Coinest is a frontend web application built using React.js and Tailwind CSS. It focuses on a clean design, responsive layout, and component-based architecture.

## Technologies Used

* React.js
* Tailwind CSS
* JavaScript (ES6+)

## Features

* Responsive user interface
* Clean and simple design
* Reusable components
* Fast performance

## Installation

Follow these steps to run the project locally:

```
git clone <your-repo-link>
cd coinest
npm install
npm run dev
```
